# Trocado — Web

App Next.js do Trocado. Instalação e visão geral no [README principal](../README.md).

```bash
cp .env.example .env.local
npm install
npm run dev          # http://localhost:3000 (a API precisa estar rodando)
```

Este projeto usa o Next.js 16, que mudou várias APIs (por exemplo, `middleware` agora é `proxy`). Veja o `AGENTS.md`.
